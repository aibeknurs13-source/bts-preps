# БТС AI — приложение для подготовки к экзамену

Веб-приложение (PWA) для подготовки к экзамену: ИИ читает ваши материалы (PDF, DOCX, PPTX, TXT) и делает по ним
**тесты, карточки и конспекты** — с тремя уровнями сложности **A / B / C**, без повторов.

Работает бесплатно, без сервера и без подписок.

---

## Возможности

| | |
|---|---|
| ✨ **AI-генератор** | Тесты / карточки / конспекты по любой теме или по вашему файлу |
| 📄 **Импорт файлов** | PDF, DOCX, PPTX, TXT, MD, CSV, JSON, HTML + картинки (OCR). Файл читается **в браузере**, на сервер не уходит |
| 📶 **3 уровня сложности** | **A** — базовый (определения, факты, формулы), **B** — средний (применение, 2–3 шага), **C** — сложный (многошаговые задачи, ловушки, интеграция тем) |
| 🔢 **20–40 вопросов** | Настраиваемое количество вопросов на каждую тему (10 / 20 / 25 / 30 / 40) |
| 🚫 **Без повторов** | Глобальный «чёрный список» отпечатков всех сгенерированных вопросов: повторные и перефразированные вопросы отбрасываются и добираются новые |
| 🧠 **Адаптивность** | Тест сам повышает/понижает сложность по ходу ответов; после теста — «адаптивный разбор» по вашим ошибкам; на «Прогрессе» видны слабые места |
| 🔁 **Повтор ошибок** | Ошибки возвращаются через 10 минут → 1 день → 3 дня (интервальное повторение) |
| 🔐 **Вход через Google** | Google Identity Services; данные привязываются к аккаунту |
| 📲 **Устанавливается как приложение** | manifest + service worker: «Установить» на телефон/ПК, работает офлайн |
| 🎨 **Современный дизайн** | Тёмная/светлая тема, glass-панели, боковое меню на ПК и нижние табы на телефоне |
| 🧮 **Калькулятор и рисование** | Научный калькулятор и слой для рисования поверх конспекта (перенесено из прошлой версии) |

## Бесплатные AI-модели

Приложение **не требует денег и не требует сервера**. Провайдеры выбираются в «Настройках»:

| Провайдер | Ключ | Комментарий |
|---|---|---|
| **Pollinations AI** *(по умолчанию)* | не нужен | Работает сразу. Бесплатный лимит — **1 запрос в 45 секунд** с одного IP, поэтому генерация идёт с паузами |
| **Google Gemini** | бесплатный ключ AI Studio | Самый быстрый и щедрый бесплатный вариант |
| **Groq** | бесплатный ключ | Очень быстрые модели |
| **OpenRouter** | бесплатный ключ | Модели с суффиксом `:free` |
| **Ollama (локально)** | не нужен | Полностью офлайн: `ollama pull llama3.2` |
| **Свой OpenAI-совместимый адрес** | по желанию | LM Studio, vLLM, Together и т.п. |

Ключи хранятся **только в вашем браузере** (localStorage) и никуда не отправляются.

> Нужны бесплатные ключи: [Google AI Studio](https://aistudio.google.com/app/apikey) · [Groq](https://console.groq.com/keys) · [OpenRouter](https://openrouter.ai/keys)

Если все провайдеры недоступны — приложение предложит **офлайн-тест**, собранный из текста вашего документа.

## Вход через Google

1. Откройте [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials).
2. Создайте **OAuth client ID** → тип **Web application**.
3. В «Authorized JavaScript origins» добавьте домен сайта:
   `https://<владелец>.github.io` и `https://<владелец>.github.io/<репозиторий>`.
4. Скопируйте Client ID и вставьте в **Настройки → Google Client ID** (или в файл `assets/js/core.js`, константа `GID_DEFAULT`).

Гостевой режим работает без авторизации — данные просто привязываются к устройству.

## Как запустить локально

Приложение полностью статическое, сервер не нужен:

```bash
git clone https://github.com/aibeknurs13-source/bts-prep.git
cd bts-prep
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как задеплоить

Репозиторий уже содержит workflow `.github/workflows/pages.yml`:

1. `Settings → Pages → Build and deployment → Source: GitHub Actions`.
2. Push в ветку `main` — приложение自动 соберётся и опубликуется на
   `https://aibeknurs13-source.github.io/bts-prep/`.

## Структура

```
index.html              — оболочка приложения (экраны, модалки, PWA-метаданные)
manifest.webmanifest    — манифест PWA (установка на телефон)
sw.js                   — service worker (офлайн-оболочка, только свой домен)
assets/css/app.css      — дизайн-система (тёмная/светлая тема, адаптив)
assets/js/core.js       — состояние, хранилище, KaTeX, markdown, графики, калькулятор, рисование
assets/js/ai.js         — провайдеры, промпты, починка JSON, движок «без повторов», адаптивность
assets/js/ingest.js     — разбор PDF / DOCX / PPTX / TXT / картинок (OCR) в браузере
assets/js/ui.js         — экраны, роутер, тест-раннер, карточки, конспекты, дашборд
```

Данные (документы, материалы) лежат в **IndexedDB**, настройки и прогресс — в **localStorage**,
всё привязано к аккаунту Google.

## Приватность

Файлы читаются локально в браузере. В AI-провайдер уходит только **извлечённый текст** выбранного
фрагмента (нужный для генерации вопросов) — никогда сам файл.
